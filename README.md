# Luma TV

Luma для Android TV: оболочка на Kotlin (WebView) и интерфейс на HTML/JS в `app/src/main/assets`. Управление только пультом.

## Что есть
- Главная: баннер с трендами TMDB, ряды каталога и TMDB, «Продолжить просмотр».
- Каталог: фильмы, сериалы, мультфильмы, аниме, ТВ-шоу; сортировки, жанры, оригинальные названия, страна и жанры под карточкой.
- Плеер: поток берётся со страницы плеера сайта и играет нативный ExoPlayer (Media3): звук, субтитры, качество, скорость, серии, пропуск заставки, продолжение с места. Если поток получить не удалось, открывается плеер сайта.
- Страница фильма: оценки с логотипами (Кинопоиск, IMDb, TMDB, Letterboxd, Rotten Tomatoes, Metacritic), вкладки «О фильме», «Серии», «Трейлеры», «Актёры», «Кадры», «Похожее», выбор сезона и серии, продолжение с места остановки.
- Актёры и режиссёры: страница человека с фильмографией из TMDB, поиск людей.
- Подборки: Letterboxd, MDBList, Trakt (поиск, популярные, сохранённые).
- Каналы: плейлисты IPTVru и свои, телепрограмма, избранное, «Недавно смотрели».
- Долгое нажатие OK на карточке: меню (избранное, убрать из истории).
- Перенос данных с телефона по QR: резервная копия Luma (.luma, с паролем), ссылки на плейлисты каналов.
- Синхронизация с ПК по сети (код с экрана ТВ), ввод ключей и плейлистов (ссылка или файл) прямо на ТВ.
- Обновление приложения из релизов GitHub (`dmitrykirsh/luma-tv`).

## Сборка
```bash
bash tools/deploy.sh                       # debug-сборка, установка на ТВ по adb, запуск
node tools/cdp.mjs "S.favs.length" --shot a.png   # отладка страницы на ТВ через DevTools
bash tools/fps.sh KEYCODE_DPAD_DOWN 8      # замер плавности
```
Релиз: `gradlew assembleRelease` (ключ подписи в `keystore.properties`, `luma-tv.jks`; их нет в репозитории, сохраните их отдельно: без ключа обновить установленное приложение нельзя). Готовый файл копируется в `dist/`.

## Сеть
Запросы страницы идут через приложение (`NetProxy.kt`): TMDB с запасным DNS-over-HTTPS и прокси картинок, потоки каналов с нужными заголовками, плейлисты, телепрограмма. Адреса, которые не работают, запоминаются и пропускаются.

## Интеграция с Luma Launcher
[Luma Launcher](https://github.com/dmitrykirsh/luma-launcher) показывает на главном экране ТВ «Продолжить просмотр», избранное, подборки и недавние каналы из Luma.
- Luma публикует ленту (история с прогрессом, избранное, подборки главной, недавние и избранные каналы) в файл и отдаёт её через `ContentProvider` `content://ws.luma.tv.feed/home.json`, только для чтения.
- Лаунчер открывает Luma по ссылкам: `luma://open?id=<фильм>&play=1` (открыть фильм и продолжить с места) и `luma://tv?id=<канал>` (включить ТВ-канал).
- Трейлеры YouTube открываются в приложении YouTube на ТВ, превью YouTube идут через локальный прокси ByeByeDPI (`127.0.0.1:1080`), если он запущен.
